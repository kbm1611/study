# Programmers Algorithm Study

이 프로젝트는 프로그래머스를 중심으로 알고리즘 문제를 공부하고, 스스로 문제를 풀어보며 풀이 과정을 정리하기 위한 개인 학습용 프로젝트입니다.

## 사용 환경

- Language: Java
- IDE: IntelliJ IDEA
- Source Root: `src`

## 목적

- 프로그래머스 알고리즘 문제 풀이 연습
- 문제 유형별 풀이 방식 학습
- 직접 구현한 풀이 코드 저장
- 반복 학습을 통한 문제 해결 능력 향상
- 완료한 문제와 다시 풀어볼 문제를 분리해서 학습 흐름 관리

## 프로젝트 구조

```text
src/
├── programmers/
│   ├── basic/
│   ├── level1/
│   ├── level2/
│   └── level3/
└── level1/
```

문제 난이도와 주제에 따라 패키지를 나누어 풀이 코드를 관리합니다.

## 풀이 관리

풀이 현황은 [PROGRESS.md](./PROGRESS.md)에서 관리합니다.

각 문제는 다음 기준으로 정리합니다.

| 항목 | 설명 |
| --- | --- |
| 난이도 | Basic, Level 1, Level 2, Level 3 등 |
| 문제명 | 프로그래머스 문제명 또는 식별 가능한 풀이 이름 |
| 상태 | 예정, 진행중, 풀이 있음, 완료, 복습필요, 개선필요, 미완 |
| 핵심 개념 | 구현, 문자열, 정렬, 해시, BFS/DFS 등 |
| 파일 | 실제 풀이 코드 위치 |

## 학습 방식

1. 문제를 직접 읽고 풀이 방향을 먼저 생각합니다.
2. 가능한 한 스스로 코드를 작성합니다.
3. 실행 결과를 확인하며 예외 상황을 점검합니다.
4. 필요하면 더 나은 풀이 방식으로 개선합니다.

## 풀이 작성 규칙

- 하나의 문제는 가능하면 하나의 패키지 또는 클래스에 정리합니다.
- 클래스명은 문제를 떠올릴 수 있는 이름으로 작성합니다.
- 풀이가 끝나면 `PROGRESS.md`의 상태와 핵심 개념을 갱신합니다.
- 시간이 지나 다시 봐야 할 문제는 `복습필요`로 표시합니다.
- 정답은 맞았지만 더 나은 풀이가 떠오르는 문제는 `개선필요`로 표시합니다.

## 커밋 메시지 예시

```text
문제명 완료
문제명 미완
문제명 개선
문제명 복습 정리
```

## 추천 학습 루틴

1. 오늘 풀 문제를 고릅니다.
2. `PROGRESS.md`에 문제를 추가하고 상태를 `진행중`으로 표시합니다.
3. 풀이를 작성하고 직접 실행해 봅니다.
4. 통과하면 상태를 `완료` 또는 `풀이 있음`으로 변경합니다.
5. 막힌 부분이나 다시 풀 부분이 있으면 `복습필요` 또는 `미완`으로 남깁니다.
